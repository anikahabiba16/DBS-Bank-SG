## Visual Language
- Core visual signature: Precision geometric badges, high-contrast security verification borders, and crisp institutional financial status tags.
- Material & depth: Subtle multi-tier elevation with 1px border contrast, soft card shadows, and dark sapphire admin panel container.
- Containers & buttons: Structured institutional card containers, crisp pill badges for roles/statuses, and accessible touch targets.
- Layout rhythm: Dense yet structured two-column management view with generous whitespace separating data groups.

## Animation
- Entrance: Subtle opacity fade-in with 150ms ease-out on modal dialogs and message feed.
- Interaction: Micro-scale feedback on active action buttons (100ms).
- Scroll / transition: Smooth container scroll for real-time messaging and customer ledger.

## Forbidden
- No flat saturated primary color fills on large background areas.
- No emoji icons in navigation, action headers, or system buttons.
- No decorative looping animations that distract from critical financial data.

## Additional Notes
- Dynamic branding parameters (Admin Sidebar Logo, Customer Portal Logo, Admin Security Panel Logo & Wallpaper Theme) load dynamically from Supabase database with instant real-time sync.
- Sub-Admin role strictly restricts visibility to assigned customer accounts at both frontend and backend queries.
